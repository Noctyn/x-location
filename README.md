# X Account Location Tagger (X 账号归属地标注)

基于 Tampermonkey 的 Twitter/X 网页端账号归属地标注脚本。通过 X 官方接口获取账号公开归属信息，在推文时间线与个人资料名片中以原生风格徽章直观呈现。

## 安装

使用前需在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey 扩展：

👉 **[点击直接安装](https://raw.githubusercontent.com/Noctyn/x-location/main/x-location.user.js)**

## 主要特性

- **双展示位置**：
  - **悬浮名片（HoverCard）**：鼠标悬停在用户头像或用户名上时，在资料卡用户名下方展示完整的所在地与连接来源。
  - **推文时间戳旁**：在时间线主推文与引用推文的时间戳右侧直接显示紧凑型国旗与归属地徽章。
- **信息识别与风控提示**：
  - **账号所在地**：基于 X 官方 `AboutAccountQuery` 返回的地理区域与对应 Emoji 国旗。
  - **连接来源标注**：标明通过移动端（如 App Store 区域）或网页端接入。
  - **区域不一致预警**：当 App Store 区域与账号所在地不一致时高亮提示。
  - **疑似代理标记**：若 X 官方标记该账号所在地可能不准确（可能使用代理/VPN），自动给出预警提示。
- **动态 Query ID 发现**：
  - 内置 X 前端 bundle 扫描机制，当 X 更新 GraphQL Query ID（导致 400/404）时，脚本会自动从网页加载的前端资源中提取最新 ID，无需等待作者手动发版更新。
- **流控与缓存**：
  - **本地缓存**：内置 24 小时持久化缓存（上限 1000 条），避免重复请求同一账号。
  - **限流退避**：请求队列控制与针对 429 的自动退避机制，防止触发 X 频率限制。
- **轻量无越权**：
  - 使用 `@grant none`，纯粹在网页原生上下文运行，不申请额外的扩展高危权限。
  - 自动适配页面语言（中文 / 英文）。
